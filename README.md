# こえログ

ワンタッチで会話を録音し、スマホの中だけで文字起こしする Web アプリ（試作版）です。

- 公開URL：https://astss1014.github.io/koelog/
- 文字起こしは Whisper（音声認識AI）をブラウザの中で動かして行います。録音した音声は外部に送信されません。
- インターネットを使うのは、アプリ本体と AI のファイルを最初にダウンロードするときだけです。
- 録音と文字起こし結果はそのブラウザの中（IndexedDB）にだけ保存されます。「テキスト保存」でファイルに書き出せます。
- 録音中は画面をつけたままにしてください。
- 設定の「録音だけモード」をオンにすると、録音中は文字起こしをせず録音だけします（電池・発熱を抑える）。
- 設定の「話者を分ける（試作）」をオンにすると、録音のあとの文字起こしで「話者1」「話者2」と発言を分けます（pyannote segmentation 3.0 をブラウザ内で実行）。
- AI 要約は未対応です。

## パソコンで清書する

スマホでは軽いAIしか動かないため、精度が必要な録音はパソコンで文字起こしし直せます。

1. スマホで録音を開き「音声を保存」を押す（`koelog_日付_時刻.m4a` などで保存される）
2. 音声ファイルをパソコンに移す（USBケーブル、Quick Share など）
3. パソコンの Chrome / Edge で公開URLを開き、設定で「最上位（パソコン向け）」を選ぶ
4. ホームの「音声ファイルを読み込んで文字起こし」からファイルを選ぶ

## ファイル構成

- `index.html` / `style.css` : 画面
- `app.js` : 録音・区切り・保存・画面操作
- `recorder-worklet.js` : マイク音声の取り出し
- `worker.js` : 文字起こし（Transformers.js で Whisper を実行）
- `vendor/` : 同梱ライブラリ（Transformers.js 3.8.1 / ONNX Runtime Web、Apache-2.0）
- `SECURITY.md` : 安全対策と脆弱性の報告方法
- `manifest.json` / `icon.svg` / `sw.js` : ホーム画面への追加・オフライン対応
